# 用語集

このリポジトリ（README・地図・メモ）に出てくる言葉を、分野ごとにまとめました。
はじめての人は先に [この地図の前提と限界](premise.md) を読んでください。

## 1. 法律・制度

| 用語 | 意味 |
|---|---|
| **法定速度** | 標識が無いときに法律で決まっている速度の上限。一般道路は長年 60 km/h だった。2026-09-01 から、中央線・車両通行帯・中央分離帯のいずれもない一般道路は **30 km/h** |
| **規制速度（指定最高速度）** | 道端の標識（青地の丸に数字）で指定された上限。**標識があれば法定速度より優先**され、今回の改正で変わらない |
| **生活道路** | 住宅地の中などの、幅の狭い日常生活用の道路。法律用語ではなく、報道や警察庁の説明で使われる通称。今回の改正は「生活道路の 30 km/h 化」と呼ばれる |
| **改正道路交通法施行令** | 法定速度を定めている政令。2024 年に改正が公布され、2026 年 9 月 1 日に施行 |
| **中央線（センターライン）** | 道の真ん中に引かれた白または黄色の線。上りと下りを分ける。道路管理者（国・県・市）が引く区画線で、**どこに引かれているかの全国データは存在しない** |
| **車両通行帯** | 片側に 2 車線以上あることを示す白の区分線（車線境界線）。警察が指定する |
| **中央分離帯** | 上りと下りを縁石・植栽・柵などで物理的に分けている帯。幅の広い幹線道路にある |
| **対象道路**（このリポジトリの言い方） | 中央線・車両通行帯・中央分離帯の**どれも無い一般道路**。法定速度が 60→30 になる構造の道路。標識があれば速度自体は変わらない |
| **ゾーン30** | ある区域の中の道路をまとめて 30 km/h に規制する制度。区域の入口に標識がある。もともと 30 なので改正で変わらない。**ゾーン30 プラス**は物理的な対策（ハンプなど）を組み合わせたもの |
| **区域規制** | ゾーン30 と同じく面で速度を指定する規制。兵庫県の瀬戸内沿岸 14 市 4 町には 1972〜74 年から「全域 40 キロ」の区域規制があったが、**2026-09-01 の法改正と同時に廃止された**（この地図が使う 2026-07 のデータにはまだ入っている） |
| **一般道路** | 高速自動車国道・自動車専用道路以外の道路。今回の改正の対象 |
| **高速自動車国道等** | 高速道路と、それに準じる自動車専用道路。法定速度は別（100 km/h など）で、今回の対象外 |
| **道路法上の道路** | 道路法で「道路」とされているもの＝**国道・都道府県道・市区町村道**（と高速自動車国道）。各道路管理者が路線を「認定」して管理する。国の道路統計はこの範囲で集計 |
| **認定路線** | 市や県が道路法に基づいて正式に「道路」と認定した路線。認定路線網図は市が管理する地図。札幌市はオープンデータで公開している |
| **私道・農道・林道** | 道路法上の道路ではないが、一般の車が通れる道。**道路交通法は及ぶ**ので、条件に当たれば 30 km/h になる。地理院の道路データには含まれ、国の道路統計には含まれない |
| **道路交通法上の「道路」** | 道路法の道路のほか、「一般交通の用に供するその他の場所」を含む。私道でも不特定の人や車が通れれば当たる。個別の判断は状況次第 |

## 2. 道路の形・幅

| 用語 | 意味 |
|---|---|
| **幅員** | 道路の幅。**車道幅員**（車が走る部分の幅）と**道路幅員**（歩道・路肩を含む道路敷全体の幅）がある。地理院の幅員区分は車道部、道路台帳の幅員は道路敷全体と考えられ、札幌で大きく食い違った |
| **幅員区分（rnkWidth）** | 地理院データの幅のクラス。0: 3 m 未満 / 1: 3〜5.5 m / 2: 5.5〜13 m / 3: 13〜19.5 m / 4: 19.5 m 以上 / 5: その他 / 6: 不明 |
| **5.5 m** | 車線 1 本（約 2.75 m）が 2 本取れる幅。これ未満だと中央線はふつう引かれない。**このリポジトリは「幅 5.5 m 未満」を「中央線なし」の代替指標**にしている。道路統計年報でも 5.5 m は幅の区切りとして使われ、全国の道路の 71% が 5.5 m 未満 |
| **車線** | 車 1 台が走る幅の帯。道路構造令では 2.75〜3.5 m |
| **実延長** | 道路の長さの統計値。重複区間や未供用を整理した「実際の」長さ。道路統計年報の基本の数字 |
| **道路台帳** | 道路管理者が路線ごとに幅・延長などを記録している帳簿・図面。閲覧はできるがデータ公開は自治体次第 |

## 3. 使っているデータ

| 用語 | 意味 |
|---|---|
| **地理院ベクトルタイル提供実験（experimental_bvmap）** | 国土地理院が実験提供している地図データ。道路中心線に幅員区分・分離帯・道路分類の属性がつく。このリポジトリの**主データ**。ズームレベル 16 のタイルを全国 216 万枚使った |
| **最適化ベクトルタイル（optimal_bvmap）** | 地理院の正式提供の地図データ。全国 1 ファイルの PMTiles（17 GB）で配布。道路の幅員区分はあるが**分離帯の属性が無い**ため、判定には使わず背景地図にだけ使っている |
| **道路中心線（RdCL）** | 道路の真ん中を通る線データ。1 本 1 本は交差点などで区切られた短い線分（全国で約 230 万 km・3,600 万本、1 本の平均は約 60 m） |
| **地物コード（ftCode）** | 地理院データの種類コード。道路中心線は 4 つの種類 × 4 つの細分（通常部・雪覆い・橋高架・トンネル）。**2701〜2704 ２条道路中心線**（2701 通常部 / 2702 雪覆い / 2703 橋・高架 / 2704 トンネル）＝このリポジトリの「車道」/ **2711〜2714 庭園路** / **2721〜2724 徒歩道** / **2731〜2734 石段** / 2201 道路縁（道路の端の線。中心線ではない） |
| **車道**（このリポジトリの言い方） | 道路中心線のうち、庭園路・徒歩道・石段を除いたもの（ftCode 2701〜2704 の２条道路中心線）。自動車が通れる幅の道路で、**割合の分母**。**地図上の形の区分であって法律上の区分ではない**ので、私道・農道・林道も（自動車が通れる幅なら）含む。道路法上の道路はこの部分集合。地理院の分類名は「通常部」 |
| **庭園路・徒歩道・石段** | ２条道路（車が通れる幅）でない細い道。「車道以外」として判定から外している。幅の狭い農道・林道はここに入っていることがあり、その分は分母（車道）にも入らない |
| **道路分類（rdCtg）** | 0 国道 / 1 都道府県道 / 2 市区町村道 / 3 高速自動車国道等 / 5 その他 / 6 不明。地理院データでは私道も「2 市区町村道」に丸められている（「5 その他」はほぼ出ない） |
| **分離帯（medSect）** | 中央分離帯の幅（m）。0 なら無し、99 は「幅員急変等で非表示」 |
| **motorway** | 高速道路フラグ。0 高速以外 / 1 高速 / **9 不明**。実データの 99% が 9 なので「1 だけ除外」している |
| **JARTIC 交通規制情報** | 日本道路交通情報センターが公開する、警察の交通規制のオープンデータ。都道府県警ごとに月次で更新。**速度標識の場所（線）**・**ゾーン30 の範囲（面）**・車両通行帯・中央線（一部の県だけ）などが入る。このリポジトリは 2026 年 7 月分を使用 |
| **共通規制種別コード** | JARTIC の規制の種類番号。112 最高速度（線）/ 114 最高速度（面＝ゾーン）/ 15 道路の中央線 / 20 車両通行帯 / 16 中央線の変移 など。**県によって提供する種類が違う**。2026 年 7 月分では 112・114 は 47 都道府県すべて、20 は 40 県、15 は 22 県が提供。各県の網羅性（漏れの有無）は未検証で、漏れは「規制なし → 変更」側に化ける |
| **道路統計年報** | 国土交通省が毎年出す道路の統計。都道府県別の実延長（国道・都道府県道・市町村道）と幅員別の内訳（表15）がある。2024 年版（2023-03-31 現在）を使用 |
| **国土数値情報 N03（行政区域）** | 国土交通省の市区町村境界データ。都道府県・市の範囲に使用 |
| **mokuroku（目録）** | 地理院タイルの全タイル一覧（CSV）。どのタイルが存在するか・サイズ・更新日が分かる |

## 4. 判定と結果の言葉

| 用語 | 意味 |
|---|---|
| **候補** | 幅 5.5 m 未満・分離帯なしの車道。中央線が無いとみなした道路（構造的に「対象道路」の推定） |
| **規制あり: 標識 XX** | JARTIC の速度規制（線）に長さの 7 割以上が重なった道路。標識の速度のまま変わらない |
| **規制あり: ゾーン XX** | JARTIC の面規制の中に長さの半分以上が入る道路。変わらない |
| **対象外: 分離帯あり / 車両通行帯あり / 高速等** | 法律の 3 条件のどれかに当たる、または高速道路。変わらない |
| **不明: 幅員 5.5 m 以上** | 幅が 5.5 m 以上で規制も無い道路。中央線があれば 60 のまま、無ければ 30 になるが、**データから判定できない** |
| **★60→30 変更（推定）** | 候補のうち規制の無かった道路。法定速度が 60 から 30 に変わったと推定 |
| **車道以外** | 庭園路・徒歩道・石段。判定から外している（データ上の名前は「非通常道路(ftCode)」。作り直したタイルでは「非車道(ftCode)」） |
| **重なり率** | 道路 1 本の長さのうち、規制線から 10 m 以内（バッファ）にある割合。**0.7 以上で「規制あり」**。単に「触れているか」で見ると、40 km/h の幹線につながる脇道が端で触れて全部「規制あり」になるため |
| **バッファ 10 m** | 規制線の周り 10 m を帯にして道路と重ねる幅。5〜20 m で試して結果はほぼ変わらない |
| **改正前の速度 / 改正後の速度（speed_before / speed_after）** | 各道路の 2026-08-31 までの上限と 9-1 以降の上限。標識の道路は同じ、変更(推定)は 60→30、不明は 60→「不明(60/30)」 |
| **構造的に対象** vs **実際に変わった** | 前者は「中央線などが無い道路」の割合（報道の「約 7 割」はこれ）。後者はそこから既存の標識・ゾーン規制を除いた「本当に速度が変わった」割合。数字が近いことがあるが意味が違う |
| **道路法道路への換算（下限〜上限）** | 地理院データには私道・農道が含まれ、国の統計（道路法上の道路だけ）と分母がずれる。市区町村道の**超過分**（地理院 − 道路統計）を全部「変更」とみなして引いた値を下限、引かない値を上限として幅で示す |
| **超過分** | 地理院の市区町村道の長さが道路統計の市町村道実延長を上回る分。ほぼ私道・農道・林道。**道路統計の市町村道を分母にすると**（以前は場所ごとに分母が違った）、埼玉 +16%、川越 +41%、札幌 +42%、全国 +70%、北海道 +92% |

## 5. 技術用語

| 用語 | 意味 |
|---|---|
| **ベクトルタイル（MVT）** | 地図を小さな正方形（タイル）に分け、線や面をそのまま数値で入れた形式。拡大しても崩れず、属性で色分けできる |
| **ズームレベル（ZL, Z）** | 地図の拡大段階。Z9 は県が画面に入る程度、Z12 は市の一部、Z16 は街区が見える程度。ZL16 のタイルは全国で 216 万枚 |
| **PMTiles** | たくさんのタイルを 1 ファイルにまとめた形式。サーバーはファイルを置くだけでよく、ブラウザが必要な部分だけ Range リクエストで読む。全国版は 6.5 GB を Cloudflare R2 で配信 |
| **tippecanoe** | GeoJSON などからベクトルタイル・PMTiles を作るツール |
| **GDAL / ogr2ogr** | 地理データの変換ツール。タイルの束を直接読めるので、Python で 1 枚ずつ解くより 20 倍速かった |
| **GeoParquet / FlatGeobuf** | 大量の地理データを速く読み書きできるファイル形式。中間データに使用 |
| **平面直角座標系（EPSG:6669〜6687）** | 日本の測量用の座標系。長さをメートルで正確に測るために都道府県ごとに系を選んで使う（埼玉 IX 系 = 6677、北海道 XII 系 = 6680） |
| **代表点で割り当て** | 都道府県の集計で、線分を県境で切る代わりに「線分の代表点がどの県に入るか」で所属を決める方法。128 万本で 20 分かかるクリップが数秒になる |
